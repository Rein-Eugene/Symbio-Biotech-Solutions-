# Weather Dashboard (Open‑Meteo)

Simple static weather dashboard that uses Open‑Meteo (no API key).

How to run
1. Save `index.html`, `styles.css`, and `script.js` in the same folder.
2. Open `index.html` in your browser (no server required).
3. Search for a city, or click "My location" to use geolocation.

Notes
- Data comes from Open‑Meteo: https://open-meteo.com/.
- Temperatures are fetched in Celsius and converted to Fahrenheit client-side when you toggle the unit switch.
- If you prefer OpenWeatherMap (more fields but requires an API key), tell me and I can adapt the code.

Deploy
- This is a static site — you can deploy it to GitHub Pages by pushing to a repository and enabling Pages in repo Settings.
